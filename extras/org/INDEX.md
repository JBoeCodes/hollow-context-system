# Organization Context Index

Optional shared layer for a team or company. One line per file. Keep it short (about 25 lines). Treat it as read-only and suggest changes through your team's review process.

- `glossary.md`: shared terms and acronyms. Load: when you meet an unfamiliar internal term.
- Add more short files as needed (for example `teams.md`, `systems.md`, `standards.md`) and list each here with a one-line `Load:` trigger.
