# Inventory Forecasting Rollout

Weekly inventory forecasts for all 12 Northwind cafes, owned by Maya Patel with Finance. Audience: cafe managers who read updates on their phones.

## Rules for this project

These override Maya's personal style while working on this project. Her Guardrails still always win.

- Updates to cafe managers: 3 bullets maximum, no tables (they read on phones).
- Always show forecasts in units, not dollars.
- Never change the shared forecast template columns without Finance approval.

## Key files or folders

- `Google Drive/Operations/Forecasting/Weekly Forecast Template`: the one shared sheet every cafe fills in.
- `Google Drive/Operations/Forecasting/Rollout Plan`: schedule and which cafes are live.

## Gotchas

- Two cafes enter Sunday counts late; forecasts for Downtown and Riverside run Monday at noon instead of 10:00 AM.
