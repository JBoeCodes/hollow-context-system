# Example Context Folder (Fictional)

What a finished Hollow Context System looks like for one fictional person, Maya Patel, an operations manager who is not a developer. Notice how short every file is.

- [`INDEX.md`](INDEX.md): the table of contents any AI reads first.
- [`me/`](me/): the four personal files.
- [`notes/`](notes/): one sample remembered note.
- [`home/work-laptop.md`](home/work-laptop.md): optional computer-specific facts.
- [`inventory-forecasting/AGENTS.md`](inventory-forecasting/AGENTS.md): optional instructions for one project, which override her personal style while she works on it.
- [`my-context.md`](my-context.md): the same facts as a single file, the way a chat-app user (Claude, ChatGPT, or Gemini Projects) would keep them.
